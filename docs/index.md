# GetXAPI MCP Server

MCP server for the [GetXAPI](https://www.getxapi.com) Twitter / X data API.

## Quick start

```bash
npx @getxapi/mcp
```

## 44 endpoints

Reads:
- search
- profiles
- follower graph
- timeline
- bookmarks
- mentions
- lists, communities, trends

Writes:
- post tweets
- like, retweet, follow
- DM, articles

## Auth

Bearer token. Get an API key at [getxapi.com](https://www.getxapi.com).
